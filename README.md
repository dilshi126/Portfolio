# Dilshi Piyumika — QA Engineer Portfolio

A personal portfolio highlighting my software quality assurance experience, testing approach, and selected projects.

## Tech stack

- Astro with TypeScript
- Responsive, accessible CSS
- Playwright for browser testing (planned)
- GitHub Actions for continuous integration (planned)

## Portfolio pages

- `/` — Home and selected work
- `/about/` — Professional summary, experience, education, and certification
- `/projects/` — Web and mobile project experience
- `/skills/` — Testing methods, automation, tools, and ways of working

## Run locally

```sh
npm install
npm run dev
```

## Quality checks

```sh
npm run check
npm run build
```

Project examples and QA materials are presented at a high level. No confidential test data or employer-owned materials are included.
